# Changelog

## Version 1.0.4
Features:
- Das App-Design wurde für iOS 26 mit Liquid Glass überarbeitet

Verbesserungen:
- Kleinere Korrekturen an der Benutzeroberfläche für ein modernes Design


## Version 1.0.3
Features:
- Dunkle Version des App-Symbols hinzugefügt

Verbesserungen:
- Verbesserte und vereinfachte Benutzeroberfläche zum Hinzufügen und Bearbeiten von Einträgen
- Verbesserte Benutzeroberfläche und Funktionsweise der Farbeinstellungen
- Animationen in Listen wurden stabiler gemacht

Fehlerbehebungen:
- Es wurde behoben, dass alte Einträge weiterhin in Widgets angezeigt wurden
- Mehrere Fehler bei der Synchronisierung und in iCloud wurden behoben


## Version 1.0.2
Verbesserungen:
- Verbessertes Widget-Design bei Verwendung größerer barrierefreier Schriftarten

Fehlerbehebungen:
- Zeigt jetzt Widgets richtig an, wenn das iOS 18 Feature "Eingefärbter Home-Bildschirm" genutzt wird

## Version 1.0.1
Features:
- Funktionsübersichtsseite in den Einstellungen hinzugefügt

Verbesserungen:
- Widget-Design verbessert
- Widgets unterstützen jetzt neue iOS-Funktionen

Fehlerbehebungen:
- Einträge, die am selben Tag enden, werden jetzt in Widgets angezeigt
- Einträge werden jetzt für länger als 7 Tage in Widgets angezeigt


## Version 1.0

Die erste Version der App.
